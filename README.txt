# مدیریت شارژ ساختمان

اپلیکیشن مدیریت شارژ ساختمان با پشتیبانی از:

- ✅ ثبت اطلاعات ساختمان
- ✅ مدیریت ساکنین (مالک / مستاجر)
- ✅ ثبت شارژ ماهیانه با تقویم شمسی
- ✅ درآمدهای متفرقه
- ✅ ثبت هزینه‌ها (بانک / تنخواه)
- ✅ تراز مالی
- ✅ خروجی PDF
- ✅ مدیریت کاربران (مدیر، سرایدار، هیئت مدیره)

## درباره پروژه

این اپلیکیشن برای مدیران ساختمان طراحی شده تا بتوانند:

1. شارژ ماهیانه واحدها را بر اساس نوع شارژ (ثابت / سرانه / متراژ) محاسبه کنند
2. هزینه‌های جاری ساختمان را ثبت کنند
3. درآمدهای متفرقه را مدیریت کنند
4. تراز مالی ماهیانه و سالیانه دریافت کنند
5. از گزارش‌ها خروجی PDF بگیرند

## تکنولوژی

- **Flutter** برای توسعه چندسکویی
- **Hive** برای ذخیره‌سازی محلی
- **shamsi_date** برای تقویم شمسی
- **pdf** و **printing** برای خروجی PDF
